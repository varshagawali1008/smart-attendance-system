## 🚀 Project Overview
The Smart Face Attendance System is built using Django and OpenCV. It uses face recognition to automatically mark attendance without manual work.

---

## 🎯 Objectives
- Replace manual attendance system  
- Improve accuracy in attendance tracking  
- Reduce human errors  
- Provide fast and automated system  

---

## ✨ Features
- Real-time face detection and recognition  
- Automatic attendance marking  
- Attendance stored in database  
- Date and time tracking  
- Secure system  
- Fast processing using OpenCV  

---

## 🛠️ Technologies Used
- Python  
- Django  
- OpenCV  
- NumPy  
- Face Recognition Library  
- SQLite (Default Django Database)  
- HTML/CSS  

---

## 🗄️ Database (SQLite)
- Stores user/student data  
- Stores attendance records  
- Lightweight database  
- Easy to use for development  
- Can be upgraded to MySQL/PostgreSQL  

---

## ⚙️ How It Works
- User face images are registered  
- Dataset is created  
- Model is trained  
- Webcam starts  
- Face is detected  
- Attendance is marked automatically  
- Data is saved in database  

---

## 📂 Project Structure
- dataset/ → Face images  
- db.sqlite3 → Database file  
- app/ → Django app  
- templates/ → HTML files  
- static/ → CSS/JS files  
- models.py → Database models  
- views.py → Logic  
- urls.py → Routing  
- train.py → Training script  
- recognize.py → Face recognition  
- manage.py → Django file  

---

## 🔧 Installation
- git clone repository  
- cd project folder  
- pip install -r requirements.txt  

---

## ▶️ Run Project
- python manage.py runserver  
- Open: http://127.0.0.1:8000/
